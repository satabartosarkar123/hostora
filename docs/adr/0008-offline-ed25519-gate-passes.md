# ADR 0008: Offline Ed25519 Signed Gate Passes

## Context
Wedding and reception venues frequently have poor or zero mobile network coverage at the entrance gate.

## Decision
Issue Ed25519-signed pass tokens (`v1.{event_key}.{pass_id}.{seats}.{exp}.{sig}`) generated by `hostora.engine.passes` and verified offline in the browser using a Service Worker, IndexedDB manifest cache, and vendored `@noble/ed25519`. Queued scans sync idempotently by `(event_key, device_id, seq)`.

## Consequences
- Instant offline pass verification and duplicate detection upon reconnection.
- Zero dietary, faith, or phone PII exposed on the gate device.

## Alternatives Considered
- Online-only database lookup on every QR scan (fails when venue Wi-Fi/cellular drops).
